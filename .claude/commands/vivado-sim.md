# Vivado Simulation Skill

Compile and run VHDL simulations using GHDL (fast, open-source) or the Vivado built-in simulator (xsim). Supports functional and post-synthesis/post-implementation simulations.

## Usage

```
/vivado-sim [options]
```

**Options (provide in your message):**
- `tb=<testbench_entity>` — Top-level testbench entity to simulate (e.g., `tb=tb_my_module`).
- `sim=ghdl|xsim` — Simulator to use (default: `ghdl` if available, else `xsim`).
- `type=rtl|post-synth|post-impl` — Simulation type (default: `rtl`).
- `time=<duration>` — Simulation run time (default: `1ms`, e.g., `time=500us`).
- `wave=yes|no` — Dump VCD/waveform file (default: `yes`).
- `gui=yes|no` — Open waveform viewer after simulation (default: `no`).

---

## What This Skill Does

1. Identifies the testbench file (`tb/<tb_entity>.vhd`).
2. Compiles RTL sources + testbench with GHDL or Vivado xsim.
3. Runs the simulation for the specified duration.
4. Parses assertion failures and `report` messages from the output.
5. Optionally opens waveform in GTKWave (GHDL) or Vivado waveform viewer (xsim).

---

## Steps to Execute

### 1. Detect simulator

```bash
which ghdl && echo "GHDL available: $(ghdl --version | head -1)"
which xsim && echo "xsim available"
```

### 2a. GHDL simulation flow

```bash
TB_ENTITY="tb_my_module"   # replace with user-specified tb
SIM_TIME="1ms"
WAVE_FILE="sim/${TB_ENTITY}.vcd"
mkdir -p sim

# Analyse all RTL sources (order matters — packages first)
ghdl -a --std=08 --work=work \
    $(find rtl/pkg  -name "*.vhd" 2>/dev/null | sort) \
    $(find rtl/core -name "*.vhd" 2>/dev/null | sort) \
    $(find rtl/top  -name "*.vhd" 2>/dev/null | sort) \
    tb/${TB_ENTITY}.vhd

# Elaborate
ghdl -e --std=08 --work=work ${TB_ENTITY}

# Simulate
ghdl -r --std=08 --work=work ${TB_ENTITY} \
    --vcd=${WAVE_FILE} \
    --stop-time=${SIM_TIME} \
    2>&1 | tee sim/${TB_ENTITY}.log
```

**Open waveform (if `gui=yes`):**
```bash
gtkwave ${WAVE_FILE} &
```

**GHDL with GHW format (more efficient for large designs):**
```bash
ghdl -r --std=08 ${TB_ENTITY} --wave=sim/${TB_ENTITY}.ghw --stop-time=${SIM_TIME}
gtkwave sim/${TB_ENTITY}.ghw &
```

### 2b. Vivado xsim flow

```bash
TB_ENTITY="tb_my_module"
SIM_TIME="1ms"
mkdir -p sim logs

# Compile
xvhdl --2008 --work work \
    $(find rtl/ -name "*.vhd" | sort) \
    tb/${TB_ENTITY}.vhd

# Elaborate
xelab --debug typical --snapshot ${TB_ENTITY}_snap \
    --timescale 1ns/1ps \
    work.${TB_ENTITY}

# Simulate
xsim ${TB_ENTITY}_snap \
    --tclbatch <(echo "run ${SIM_TIME}; quit") \
    --wdb sim/${TB_ENTITY}.wdb \
    2>&1 | tee sim/${TB_ENTITY}.log
```

**Open Vivado waveform (if `gui=yes`):**
```bash
xsim --gui sim/${TB_ENTITY}.wdb &
```

### 3. Post-synthesis simulation

Use the netlist generated by Vivado synthesis:

```bash
# Export VHDL netlist from Vivado
vivado -mode batch -source - <<'EOF'
open_checkpoint checkpoints/synth.dcp
write_vhdl -mode funcsim -force sim/netlist_funcsim.vhd
EOF

# Compile netlist + simulation libraries + testbench
xvhdl --2008 \
    /opt/Xilinx/Vivado/*/data/vhdl/src/unisims/unisim_VCOMP.vhd \
    sim/netlist_funcsim.vhd \
    tb/${TB_ENTITY}.vhd
```

### 4. Post-implementation timing simulation

```bash
vivado -mode batch -source - <<'EOF'
open_checkpoint checkpoints/impl.dcp
write_vhdl -mode timesim -sdf_anno true -force sim/netlist_timesim.vhd
write_sdf -force sim/netlist_timesim.sdf
EOF
```

Note: Timing simulation is slow; prefer STA reports for timing closure.

### 5. Parse results

```bash
# Check for assertion failures
grep -E "(FAIL|Error|assert|failure)" sim/${TB_ENTITY}.log | grep -iv "no error"

# Check for successful completion marker
grep -i "simulation complete\|PASS\|test passed" sim/${TB_ENTITY}.log
```

### 6. Report to user

- **PASS/FAIL** summary based on assertion outputs.
- List any `assert` failures with severity, message, and time stamp.
- List any unexpected `report` messages at severity `warning` or higher.
- Waveform file location (if generated).

## Testbench Template

When a testbench does not exist for a module, generate this template:

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity tb_<module_name> is
end entity tb_<module_name>;

architecture sim of tb_<module_name> is

    -- DUT ports
    signal clk     : std_logic := '0';
    signal rst     : std_logic := '1';
    -- <add other ports>

    -- Constants
    constant CLK_PERIOD : time := 10 ns;  -- 100 MHz

begin

    -- Clock generation
    clk <= not clk after CLK_PERIOD / 2;

    -- DUT instantiation
    dut : entity work.<module_name>
        port map (
            clk => clk,
            rst => rst
            -- <map other ports>
        );

    -- Stimulus process
    stim : process
    begin
        -- Hold reset
        rst <= '1';
        wait for CLK_PERIOD * 5;
        rst <= '0';

        -- TODO: add stimulus

        wait for CLK_PERIOD * 100;

        -- Self-check assertions
        assert false report "Simulation complete" severity note;
        std.env.stop;  -- VHDL-2008 clean stop
    end process stim;

end architecture sim;
```

## Useful GHDL Flags

| Flag | Description |
|---|---|
| `--std=08` | Use VHDL-2008 |
| `--warn-no-hide` | Warn on hidden declarations |
| `--warn-library` | Warn on library issues |
| `--ieee=synopsys` | Allow Synopsys packages (legacy only) |
| `--stop-time=<t>` | Simulation stop time |
| `--wave=<file>.ghw` | GHW waveform dump |
| `--vcd=<file>.vcd` | VCD waveform dump |
| `--assert-level=error` | Fail on any error-severity assert |
