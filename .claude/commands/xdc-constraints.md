# XDC Constraints Skill

Generate, review, and validate Xilinx Design Constraints (XDC) files for AMD Xilinx FPGA designs.

## Usage

```
/xdc-constraints [action] [options]
```

**Actions:**
- `/xdc-constraints generate` — Generate an XDC template from the current top-level VHDL entity.
- `/xdc-constraints review` — Review existing XDC files for completeness and correctness.
- `/xdc-constraints timing` — Generate timing constraint templates for common clock topologies.

**Options:**
- `part=<part>` — Target device (e.g., `part=xcku5p-ffvb676-2-e`).
- `board=<board>` — Known board preset (e.g., `board=kcu116`, `board=zcu102`, `board=arty-a7`).
- `file=<path>` — XDC file to review (default: all files in `constraints/`).

---

## What This Skill Does

1. Parses the top-level VHDL entity to extract all port names.
2. Generates XDC stubs for each port (location + I/O standard).
3. Generates timing constraints for detected or user-specified clocks.
4. Reviews existing XDC files for unconstrained ports, missing clocks, and common errors.

---

## Steps to Execute

### Action: `generate`

#### 1. Extract top-level ports from VHDL

Read the top-level entity file (usually `rtl/top/*.vhd`) and identify all ports. Group into:
- Clock inputs (names containing `clk`, `clock`)
- Reset inputs (names containing `rst`, `reset`)
- Data inputs/outputs
- Differential pairs (names ending in `_p` / `_n`)

#### 2. Generate XDC template

**Template structure: `constraints/pins.xdc`**
```tcl
##############################################################################
# Pin Constraints — <project_name>
# Device: <part>
# Board:  <board>
# Generated by /xdc-constraints skill
##############################################################################

# ── Clocks ──────────────────────────────────────────────────────────────────
# Primary 100 MHz system clock
set_property PACKAGE_PIN  <PIN>     [get_ports clk_100mhz]
set_property IOSTANDARD   LVDS      [get_ports clk_100mhz]
# (For single-ended: IOSTANDARD LVCMOS33 / LVCMOS18 / HSTL_I etc.)

# ── Resets ──────────────────────────────────────────────────────────────────
set_property PACKAGE_PIN  <PIN>     [get_ports rst_n]
set_property IOSTANDARD   LVCMOS33  [get_ports rst_n]

# ── User IO ─────────────────────────────────────────────────────────────────
# <port_name>
set_property PACKAGE_PIN  <PIN>     [get_ports <port_name>]
set_property IOSTANDARD   LVCMOS33  [get_ports <port_name>]

# ── Differential Pairs ──────────────────────────────────────────────────────
# set_property PACKAGE_PIN  <PIN_P>   [get_ports <sig_p>]
# set_property IOSTANDARD   LVDS      [get_ports <sig_p>]
# (Vivado auto-resolves the _n pin from the _p pin for differential pairs)
```

**Template structure: `constraints/timing.xdc`**
```tcl
##############################################################################
# Timing Constraints — <project_name>
# Generated by /xdc-constraints skill
##############################################################################

# ── Primary Clocks ───────────────────────────────────────────────────────────
create_clock -period 10.000 -name clk_100 -waveform {0.000 5.000} \
    [get_ports clk_100mhz]

# ── Generated Clocks (MMCM/PLL outputs) ─────────────────────────────────────
# create_generated_clock -name clk_200 \
#     -source [get_pins mmcm_inst/CLKIN1] \
#     -multiply_by 2 \
#     [get_pins mmcm_inst/CLKOUT0]

# ── Input / Output Delays ────────────────────────────────────────────────────
# set_input_delay  -clock clk_100 -max 3.000 [get_ports data_in[*]]
# set_input_delay  -clock clk_100 -min 1.000 [get_ports data_in[*]]
# set_output_delay -clock clk_100 -max 2.000 [get_ports data_out[*]]
# set_output_delay -clock clk_100 -min 0.500 [get_ports data_out[*]]

# ── Clock Domain Crossings ───────────────────────────────────────────────────
# Asynchronous CDC — false paths
# set_false_path -from [get_clocks clk_a] -to [get_clocks clk_b]

# Measured CDC — max delay only (synchronizer with known latency)
# set_max_delay -datapath_only \
#     -from [get_clocks clk_a] \
#     -to   [get_clocks clk_b] \
#     5.000

# ── Multicycle Paths ────────────────────────────────────────────────────────
# Two-cycle path (setup relaxed, hold tightened by same amount)
# set_multicycle_path -setup 2 -from [get_cells src_reg] -to [get_cells dst_reg]
# set_multicycle_path -hold  1 -from [get_cells src_reg] -to [get_cells dst_reg]

# ── False Paths ──────────────────────────────────────────────────────────────
# Async reset deassert (safe to false-path in most designs)
# set_false_path -from [get_ports rst_n]

# ── Configuration / Bitstream ────────────────────────────────────────────────
# set_property BITSTREAM.GENERAL.COMPRESS TRUE [current_design]
# set_property BITSTREAM.CONFIG.SPI_BUSWIDTH 4  [current_design]
```

### Action: `review`

Check existing XDC files:

```bash
# List unconstrained ports (run inside Vivado after synthesis)
vivado -mode batch -source - <<'EOF'
open_checkpoint checkpoints/synth.dcp
set unconstrained [get_ports -filter {IS_CONSTRAINED == 0}]
if {[llength $unconstrained] > 0} {
    puts "UNCONSTRAINED PORTS:"
    foreach p $unconstrained { puts "  $p" }
} else {
    puts "All ports are constrained."
}
EOF
```

Also check for:
1. **Missing `create_clock`** — verify every clock source has a timing constraint.
2. **Unconstrained CDC paths** — look for signals crossing clock domains without `set_false_path` or `set_max_delay`.
3. **Deprecated constraints** — `TNM`, `TIMESPEC`, `PERIOD` (pre-Vivado UCF syntax) should be replaced.
4. **Missing I/O standards** — every port needs `IOSTANDARD`.
5. **I/O bank voltage conflicts** — ensure all ports in the same I/O bank use the same VCCO voltage.

### Action: `timing`

Generate timing templates for common clock topologies:

**Single MMCM/PLL:**
```tcl
create_clock -period 10.000 -name sys_clk [get_ports sys_clk_p]
create_generated_clock -name clk_200mhz \
    -source [get_pins clk_wiz_0/inst/mmcm_adv_inst/CLKIN1] \
    -multiply_by 2 \
    [get_pins clk_wiz_0/inst/mmcm_adv_inst/CLKOUT0]
create_generated_clock -name clk_50mhz \
    -source [get_pins clk_wiz_0/inst/mmcm_adv_inst/CLKIN1] \
    -divide_by 2 \
    [get_pins clk_wiz_0/inst/mmcm_adv_inst/CLKOUT1]
```

**GT (SerDes) recovered clock:**
```tcl
create_clock -period 3.103 -name gt_rxclk [get_pins gt_inst/RXOUTCLK]
set_clock_groups -asynchronous \
    -group [get_clocks sys_clk] \
    -group [get_clocks gt_rxclk]
```

## Common Constraint Mistakes

| Mistake | Consequence | Fix |
|---|---|---|
| No `create_clock` on input clock port | Vivado ignores all timing on that domain | Add `create_clock` with correct period |
| `set_false_path` on entire CDC instead of data path | Masks hold violations | Use `-from` `-to` cells, not clocks |
| Missing `-datapath_only` on `set_max_delay` for CDC | Vivado still checks hold; may over-constrain | Always add `-datapath_only` for async CDC |
| I/O standards mismatched to bank voltage | DRC error / hardware damage | Match IOSTANDARD to PCB-defined VCCO |
| `set_multicycle_path` without matching `-hold` | Hold violations introduced | Always pair setup MCP with hold MCP |
| Forgetting `BUFG` output as clock source | Generated clock not recognized | Use `get_pins` on BUFG/MMCM output, not wire |
